## 🌟 Key Highlights & Architecture

- **Visual & Brand Identity**: Custom **MS** geometric monogram logo, dark luxury obsidian palette (`#030712`), cyber blue accents (`#00f2fe` / `#4facfe`), and clean glassmorphic elevations.
- **Cinematic Transitions & Dynamic Section Animation**: Custom CSS section transition effects creating a dynamic feel as users navigate between sections.
- **Interactive ESP8266 & Sensor Test Bench**: A built-in virtual hardware simulator in the browser running telemetry loops (Flame sensor, MQ-2 Gas sensor, DHT11, Fire threshold triggers).
- **Flagship Project Ecosystem**: Deep links to verified LinkedIn engineering posts, GitHub repositories, and interactive architectural schematics.
- **Real-Time GitHub Integration**: Asynchronous live repository and commit metric synchronization directly via GitHub REST APIs.
- **Zero Heavy Framework Bloat**: 100% pure vanilla HTML5, CSS3, and JavaScript for instantaneous 60 FPS rendering, zero dependencies, and top Lighthouse scores.

## 💻 Local Setup & Development

To preview or run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mesanda456/mesanda-portfolio.git
   cd mesanda-portfolio
   ```

2. **Serve locally with Python**:
   ```bash
   python3 -m http.server 8000
   ```

3. **Open in browser**:
   Navigate to [http://localhost:8000](http://localhost:8000).
